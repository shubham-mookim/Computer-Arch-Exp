1. High-Level System Architecture

Core Idea: Instead of always pulling data to a compute node, this framework decides whether to send the code to where the data lives — saving massive network transfer when data >> code.

4. Crossover Point Visualization

6. Data Gravity Concept (Experiment 3)

Data Gravity: For multi-source joins, move smaller datasets to the node holding the largest dataset. The "heaviest" data attracts computation.
